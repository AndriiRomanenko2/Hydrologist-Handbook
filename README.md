# Hydrologist-Handbook

КУРСОВА РОБОТА З ОБ'ЄКТНО ОРІЕНТОВАНОГО ПРОГРАМУВАННЯ

Завдання:
Довідник гідролога. Річки світу: довжина (від джерела до впадіння),
куди впадає (в іншу річку, море або озеро), річний стік, площа басейну.
Обчислення річного стоку та площі басейну для заданої великої річки (разом з
її притоками), моря або озера.
